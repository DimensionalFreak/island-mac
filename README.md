# Island for Mac

A small, native Mac "island": a black, borderless window that blends into the notch (or a black pill at the top centre on Macs without one) and grows with a spring animation to show short live messages. Swift + SwiftUI, no web views, does nothing while idle.

**Status: early test build, for friends only.** The app is locked and does nothing until you paste an activation code from the owner. See `mac/HOW-TO-INSTALL-MAC.md`.

- Download: the newest build under **Releases** (`Island-mac.zip`).
- Message format other apps can send: `shared/MESSAGES.md`.
- Source: `mac/Sources/Island/`. Built by GitHub Actions (`.github/workflows/mac-build.yml`).
